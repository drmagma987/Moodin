# Decisions

Last updated: August 12, 2026

## 2026-08-12

- Start with provider-neutral TypeScript modules instead of direct provider clients.
- Keep the first draft engine deterministic and fixture-backed before live provider auth is added.
- Preserve Yahoo as authoritative league state while treating acquisition as an interchangeable provider.
- Classify RotoBaller as conditional and Tank01 as experimental until their unique value is demonstrated.
- Add a dedicated `/fantasy-football` kickoff route instead of replacing existing Moodin flows immediately.
