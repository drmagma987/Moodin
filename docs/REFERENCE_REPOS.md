# Reference Repositories

Last updated: August 12, 2026

These are analytical references, not dependencies.

## Priority references

- `kych23/ff_predictors`
  - Useful for distribution-aware projections and variance framing.
- `SamHerd/fantasy-football-draft-optimizer`
  - Useful for VORP, tiers, and draft-optimizer framing.
- `jjti/ff`
  - Useful for raw-stat-to-custom-scoring patterns.
- `faverogian/nfl-fantasim`
  - Useful for Monte Carlo draft strategy ideas.
- `nflverse/nflreadpy`
  - Useful for player stats, IDs, snaps, opportunity, and open-data ingestion.
- `uberfastman/yfpy`
  - Useful when official Yahoo API access becomes available. Review license and auth flow before adoption.
- `derekrbreese/fantasy-football-mcp-public`
  - Useful for Yahoo roster, lineup, and waiver pattern reconnaissance.
- `amarvin/fantasy-football-bot`
  - Useful for add/drop and roster optimization references.
- `cbratkovics/fantasy-football-ai`
  - Useful as a reference for midseason opportunity modeling ideas.

## Rule for using references

- Reuse ideas and patterns, not opaque logic.
- Prefer isolated borrowing over large framework adoption.
- Check maintenance status, license, and complexity before integrating anything.
